#HTML Basic Practice

This repository contains my practice projects for mastering semantic HTML fundamentals.

## 📌 Projects Included

- **Portfolio Page**  
  A personal profile page structured using semantic HTML elements.

- **Blog Structure Page**  
  A multi-article blog layout using `<article>`, `<section>`, `<header>`, `<footer>`, and `<figure>` elements.

## 🎯 Learning Focus

- Proper use of semantic HTML elements
- Article vs Section hierarchy
- Accessible image usage with `<figure>` and `<figcaption>`
- Clean document structure and heading hierarchy

## 🚀 Goal

Building a strong HTML foundation before moving into CSS and JavaScript.
